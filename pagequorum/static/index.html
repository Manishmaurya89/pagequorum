    How it works
    A quorum, not a guess.
    
      
    Every popular extractor has blind spots, and none tells you when it failed. pagequorum asks three of them about every block of the page and keeps only what they agree on.
    
    
    
    
    
      
    1
    Fetch politely
    robots.txt and crawl delays are respected; character sets are decoded the way a browser does.
    
      
    2
    Vote on every block
    trafilatura, readability and resiliparse (plus the page's own JSON-LD) each choose. Menus, ads and "related stories" fall out.
    
      
    3
    Keep the structure
    Headings, tables, code and lists become clean Markdown, in any language and script.
    
      
    4
    Chunk and cite
    Chunks never split a table row or a code line, carry their section path and link to the exact passage.
    
    
    
  
    

  
  
    
    
    
      
    API
    Three modes, one HTTP API.
    
      
    Everything the playground does is a JSON API on this server. Full schemas are in the API reference, and you can send test requests from the interactive console.
